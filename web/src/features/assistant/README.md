# Панель вопросов к графу

`AssistantPanel` показывает вопрос, ответ, режим разбора, ограничения и основания. Счета открываются
на карте по точной строке `gid`. Панель не вычисляет роли и не подменяет ответ сервера.

```tsx
import { AssistantPanel } from './features/assistant';

<AssistantPanel
  selection={selectedGid ? [selectedGid] : []}
  onSelectNode={selectGid}
/>
```

Свойство `className` необязательно. Стили входят в компонент и используют токены `--wb-*` просмотрщика.
В слот с прежними свойствами `focusGid` и `onSelectGid` нужно передать
`selection={focusGid ? [focusGid] : []}` и `onSelectNode={onSelectGid}`. Проверку наличия счёта
в индексе выполняет обработчик просмотрщика. Не задавайте панели ключ, меняющийся вместе со счётом:
это удалит историю при переходе по основанию.

Панель отправляет только `POST /api/assistant` с `{question, selection}`. История остаётся в памяти
компонента и не входит в следующий запрос. Каждый вопрос сохраняет собственный снимок выбора;
повтор использует этот снимок. Вопрос ограничен 2 000 символами. Запрос можно остановить;
через 60 секунд ожидание прекращается с сообщением. Поздний ответ отменённого запроса игнорируется.

Ожидаемые поля: `answer_md`, `nodes`, `intent`, `args`, `parser`, `warnings`, `citations`, `tool_trace`,
необязательное `model`. `nodes` принимает строки `gid` или объекты с `gid`. Основание принимает
строку либо объект с `label/title/source/kind`, а также строковыми `gid/src/dst/seed_gid/gids`.
Исходный объект основания и журнал операций доступны в раскрываемых блоках. Числовые идентификаторы
отвергаются: восстановить точный `int64` после округления в JavaScript нельзя.

`parser=openai` подписан «Разбор запроса: OpenAI»; `rules` — «Локальный разбор · без модели»;
`none` — «Запрос не распознан». Одно поле `model` не включает подпись OpenAI. До первого ответа
доступность модели не заявляется. Ключи и адреса внешних API в компоненте отсутствуют.

Поддерживается ограниченный Markdown: заголовки, абзацы, маркированные списки, выделение и код.
HTML, изображения и ссылки из текста не исполняются. Навигация доступна через отдельные кнопки
счетов и оснований. Эта граница сохраняет проверяемую связь между действием и точным идентификатором.

Проверки после установки зависимостей просмотрщика, из `web/`:

```bash
npm run typecheck
npx vitest run --config src/features/assistant/vitest.config.ts
```

Проверки `ASSIST-01`–`ASSIST-14` включают параметризованные случаи: соседние большие идентификаторы,
границы `int64`, испорченные ссылки, происхождение ответа, работу без модели, тело POST, ошибки,
отмену и безопасный показ. Данные этих проверок синтетические. Они не подтверждают доступность
реальной модели, форму ответа действующего сервера или качество отображения в браузере.

Для проверки в браузере нужны светлая и тёмная темы, ширины 375 и 1440 пикселей, клавиатура,
увеличение текста, медленный ответ, остановка с последующим запросом, ошибка с повтором,
локальный ответ без ключа, ответ с `parser=openai`, длинный ответ и переход по точному `gid`.
Матрица состояний записана в `surface.manifest.json`; результат браузерной проверки фиксируется отдельно.
