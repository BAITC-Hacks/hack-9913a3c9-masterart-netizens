# Сохранённые счета

Аналитик сохраняет счета по ходу проверки, возвращается к ним из отдельного списка и открывает PDF-отчёт
по отмеченным счетам или справку PDF по открытому счёту прямо в рабочем месте. Список переживает
перезагрузку страницы и привязан к набору данных: у другого файла анализа свой список.

## Подключение

```tsx
import {ShortlistProvider, SaveAccountButton, AccountReportButton, ShortlistPanel} from '../features/shortlist';

// Workbench.tsx — один список и одно окно просмотра PDF на всё рабочее место
<ShortlistProvider index={index}>…</ShortlistProvider>

// EvidencePanel.tsx — рядом с <CopyGid gid={node.gid} />
<SaveAccountButton gid={node.gid} />
<AccountReportButton gid={node.gid} mode={mode} />

// Отдельный вид, например вкладка «Сохранённые»
<ShortlistPanel index={index} mode={mode} current={selected} onOpen={select} />
```

Стили подключает `index.ts` этой папки. Компоненты принимают и явный `controller` из `useShortlist(index)`,
если провайдер не нужен.

| Файл | Что делает |
|---|---|
| `store.ts` | Список без React: чтение, проверка, запись, выбор для отчёта, «Вернуть» |
| `useShortlist.tsx` | Хук и `ShortlistProvider`: один контроллер на рабочее место, синхронизация вкладок |
| `SaveAccountButton.tsx` | Кнопка «Сохранить» / «Сохранён» у счёта |
| `ShortlistPanel.tsx` | Список сохранённых: открыть, убрать, вернуть, отметить, показать отчёт PDF |
| `report.ts` | Запрос `POST /api/report` и проверка, что пришёл настоящий PDF |
| `reportSession.ts` | Один просмотр PDF: запрос, ожидание, файл или ошибка; временная ссылка на файл освобождается |
| `ReportDialog.tsx` | Окно просмотра PDF («Скачать», «Открыть в новой вкладке») и кнопка «Справка PDF» по счёту |

## Как хранится

- Ключ `finance-workbench:shortlist:v1:<input_sha256>`, значение `{"v":1,"gids":["999000001834368100", …]}`.
  В хранилище только строки gid: ни анализа, ни сумм, ни ключей доступа.
- gid — строка из цифр. 18-значные номера больше `Number.MAX_SAFE_INTEGER`; число в сохранённом списке
  значит, что точность уже потеряна, поэтому такая запись отбрасывается, а не превращается в строку.
- Список другого набора данных не читается и не перезаписывается.

| Ситуация | Что видит аналитик |
|---|---|
| Хранилище запрещено (приватный режим) | «Браузер не разрешает сохранять данные… Список действует до перезагрузки страницы.» |
| Запись не удалась (переполнение) | «Не удалось записать список… пропадут после перезагрузки.» Следующая удачная запись убирает сообщение |
| Значение не читается | «Сохранённый список не удалось прочитать, начат новый.» |
| Часть записей не точные gid | «…N счетов без точного gid пропущены, остальные на месте.» |
| Счёта нет в текущем анализе | «N счетов из сохранённых нет в текущем анализе — они скрыты.» |

## PDF-отчёт

`POST /api/report` с телом `{"gids": [строки gid в порядке списка], "mode": "structural" | "strict" | "same_day"}`;
`mode` — текущий режим дат рабочего места. Не больше 25 счетов в одном отчёте, как на сервере.
Файл сохраняется, только если ответ 2xx, тип `application/pdf` и тело начинается с `%PDF-`. Страница HTML
или JSON вместо PDF не скачивается: панель показывает причину. 404 без ответа обработчика и 405/501 —
«PDF-отчёт на этом сервере не подключён»; 503 — «временно недоступен»; текст ошибки сервера из JSON
`{"error": …}` показывается как есть, до 200 символов. Ожидание ограничено 60 секундами.

Готовый файл открывается в модальном окне встроенным просмотрщиком браузера. Рядом всегда есть
«Скачать» и «Открыть в новой вкладке»: если браузер не показывает PDF внутри страницы (так бывает на
телефонах), окно говорит об этом и оставляет эти две ссылки. Временная ссылка на файл (`blob:`)
освобождается при закрытии окна, при новом запросе и при смене набора данных. Esc закрывает окно.

## Проверки

```bash
cd web
npx vitest run --config src/features/shortlist/vitest.config.ts
```

| ID | Что проверяется |
|---|---|
| `SHORTLIST-SAVE` | Сохраняется точный gid; повтор ничего не меняет и не пишет |
| `SHORTLIST-REMOVE` | Счёт убирается и возвращается на прежнее место |
| `SHORTLIST-RELOAD` | Список переживает перезагрузку и изменения из другой вкладки |
| `SHORTLIST-DATASET` | У другого набора данных свой список, прежний не тронут |
| `SHORTLIST-CORRUPT` | Нечитаемое значение и неточные записи; число не превращается в строку |
| `SHORTLIST-UNKNOWN` | Счёт не из текущего анализа не сохраняется и скрывается |
| `SHORTLIST-EXACT18` | Соседние 18-значные gid различаются, хотя как числа совпадают |
| `SHORTLIST-OFFLINE` | Без хранилища список работает в памяти и говорит об этом |
| `SHORTLIST-SELECT` | Выбор для отчёта: все, часть, ничего |
| `SHORTLIST-PRIVACY` | В хранилище только список gid под ключом набора данных |
| `SHORTLIST-REPORT` | В запросе точные gid и режим; принимается только настоящий PDF |
| `SHORTLIST-REPORT-REJECT` | HTML, JSON, 4xx/5xx, сеть, пустой выбор, предел и тайм-аут не дают «PDF» |
| `SHORTLIST-UI` | Кнопка, пустой вид, список, открытый счёт, выбор, предел и сообщения |
| `SHORTLIST-PREVIEW` | Ссылка на файл только для настоящего PDF, освобождается; «Повторить»; окно и справка по счёту |

## Ограничения

- Список хранится в этом браузере на этом устройстве. Другой браузер его не видит; очистка данных сайта
  его удаляет.
- Выбор счетов для отчёта не сохраняется: после перезагрузки отмечены все сохранённые.
- Содержание PDF собирает сервер (`reports.render_pdf`); эта папка только запрашивает и проверяет файл.
