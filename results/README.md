# Выгрузки на данных организаторов

Три обязательные выгрузки задания, полученные командой `./run.sh` на данных кейса:

| Файл | Содержание |
|---|---|
| [nodes_roles.csv](nodes_roles.csv) | Все 2 248 счетов: роль, опора роли, кластер, приоритет, основание |
| [clusters.csv](clusters.csv) | 92 кластера: размер, исходные клиенты, внутренний оборот, ключевые счета, гипотеза |
| [top_nodes.csv](top_nodes.csv) | 30 счетов очереди проверки с обоснованием — за пределами списка 81 исходного клиента |

[run_receipt.json](run_receipt.json) фиксирует отпечаток входных данных `input_sha256` и время расчёта.

Файлы не написаны вручную: повторный запуск на тех же данных создаёт в `out/` побайтно такие же три
CSV, это проверяет тест `test_F01_deterministic_rerun_bytes`. Проверить самостоятельно:

```bash
./run.sh --no-serve
for f in nodes_roles.csv clusters.csv top_nodes.csv; do cmp out/$f results/$f && echo "$f совпадает"; done
```

Роли и приоритеты — гипотезы для проверки аналитиком, а не утверждения о виновности.
